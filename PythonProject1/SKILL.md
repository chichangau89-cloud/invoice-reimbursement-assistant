# 报销合规审核助手

本项目技能用于企业报销自动化审核。它将报销单、发票、行程单、审批单、预算数据、报销制度和历史入账记录统一纳入校验流程，输出可追溯的审核结论、风险原因、退回补正建议和费用科目推荐。

本项目技能不替代企业财务负责人、税务顾问、审计人员或预算管理人的最终判断。涉及制度解释空间、异常高额支出、疑似舞弊、税务争议、跨期入账、关联交易、预算占用争议或企业制度未覆盖事项时，应输出“人工复核”。

## 一、适用对象与目标

- **适用对象**：财务共享中心、费用会计、业务审批人、预算管理员、内审人员、报销系统产品与实施团队。
- **典型场景**：差旅报销、交通费报销、住宿费报销、招待费报销、办公费报销、培训费报销、会议费报销、项目费用报销、采购垫付报销。
- **核心目标**：识别材料、校验完整性、执行制度规则、检查预算、比对历史入账、防止重复报销、推荐费用科目，并给出“通过 / 退回 / 人工复核”结论。
- **输出原则**：结论必须附带依据、命中规则、风险等级、建议动作和无法判断的数据缺口。

## 二、输入材料

### 2.1 报销业务材料

- **报销单**：报销单号、申请人、部门、成本中心、项目、报销类型、金额、币种、业务事由、费用发生期间、收款账户、审批状态。
- **发票**：增值税专用发票、增值税普通发票、电子发票、数电票、卷式发票、定额发票、通行费发票、出租车票、机票或火车票凭证等。
- **行程单**：机票行程单、火车票、网约车行程单、酒店水单、差旅平台订单、住宿明细、会议或培训签到记录。
- **审批单**：出差申请、招待申请、采购申请、预算申请、超标准审批、事前审批记录、特殊授权说明。
- **补充材料**：合同、付款截图、刷卡记录、消费明细、参会名单、接待对象、项目编号、验收单、入库单、领用记录、业务说明。

### 2.2 校验依据

- **报销制度**：费用类别、报销标准、审批层级、附件要求、禁止事项、时效要求、税务要求、特殊授权规则。
- **预算数据**：年度预算、月度预算、项目预算、部门预算、成本中心余额、预算冻结、预算追加、预算占用记录。
- **历史入账记录**：已报销记录、已入账凭证、发票号码、订单号、行程信息、供应商、员工、金额、日期、费用科目。
- **主数据**：公司抬头和税号、员工、部门、岗位职级、成本中心、项目、供应商、客户、费用科目表、税率、城市标准。
- **企业口径配置**：费用分类口径、预算控制粒度、审批权限矩阵、科目映射规则、风险阈值和例外规则。

## 三、能力地图

| 能力 | 触发意图 | 关键输入 | 关键输出 |
|---|---|---|---|
| 单据识别 | 识别发票、行程单、审批单、附件 | 图片、PDF、电子票据、报销表单 | 结构化字段、识别置信度、缺失字段、疑点字段 |
| 材料完整性校验 | 附件是否齐全、缺什么材料 | 报销类型、附件清单、制度要求 | 缺失材料、材料不一致项、补充建议 |
| 制度合规校验 | 是否符合报销制度、是否超标 | 费用事项、金额、城市、职级、审批记录 | 合规项、违规项、制度依据、处理建议 |
| 预算校验 | 预算是否充足、是否可占用 | 成本中心、项目、期间、金额 | 预算余额、占用结果、超预算提示 |
| 历史入账比对 | 是否重复报销、是否已入账 | 发票号、订单号、行程、员工、金额、日期 | 重复风险、相似记录、比对依据 |
| 费用科目推荐 | 应入哪个费用科目 | 发票项目、费用性质、部门、项目、历史习惯 | 推荐科目、候选科目、置信度、依据 |
| 审核结论输出 | 通过、退回、人工复核 | 全部识别和校验结果 | 结论、原因、风险等级、后续动作 |

## 四、工作流程

### 4.1 单据识别与结构化

1. 识别报销单字段：单号、申请人、部门、成本中心、项目、费用类型、费用期间、金额、币种、业务事由、审批状态。
2. 识别发票字段：发票代码、发票号码、开票日期、销售方、购买方、税号、项目名称、规格型号、数量、金额、税额、价税合计、税率、发票类型、校验码。
3. 识别行程字段：出行人、出发地、目的地、出发时间、到达时间、交通工具、订单号、票价、服务费、退改签信息。
4. 识别审批字段：申请人、部门、审批事项、事由、预算归属、审批链路、审批时间、审批状态、审批金额、特殊授权说明。
5. 对识别结果打标：明确标记“已识别 / 缺失 / 低置信 / 冲突 / 需复核”，避免把不确定字段当作事实。

### 4.2 材料完整性校验

按报销类型匹配必需材料：

- **差旅费**：出差审批单、交通票据、住宿发票、行程明细、出差日期与地点说明。
- **市内交通费**：行程单、发票、出发地、目的地、业务事由。
- **住宿费**：住宿发票、酒店水单、入住离店日期、入住人、差旅审批或会议培训证明。
- **招待费**：事前审批、招待对象、人数、事由、发票、消费明细、超标准审批。
- **办公费或采购垫付**：采购审批、发票、明细清单、验收或领用记录。
- **培训费 / 会议费**：审批单、通知或邀请、参会名单、签到记录、合同或报价、发票。

校验输出应区分：

- **缺失材料**：制度明确要求但未提交。
- **材料不一致**：发票、行程单、审批单、报销单之间的人员、日期、地点、金额或事项不匹配。
- **材料需解释**：制度允许例外，但需要业务说明、特殊审批或财务判断。

### 4.3 制度与财务合规校验

对照企业制度和财务规则执行以下检查：

1. 发票抬头、税号、购买方信息是否与公司主数据一致。
2. 开票日期、消费日期和报销期间是否满足报销时效。
3. 金额是否超过城市、职级、费用类别、项目或客户标准。
4. 事前审批是否存在，审批金额是否覆盖报销金额，审批时间是否早于费用发生时间。
5. 发票项目名称是否与报销事项一致，是否包含制度禁止报销内容。
6. 税率、税额、价税合计是否逻辑一致，专票抵扣条件是否满足企业要求。
7. 是否存在跨部门、跨项目、跨期间、跨成本中心归属异常。
8. 是否存在拆分报销规避审批、拆分发票规避标准、同日同供应商高频消费等异常模式。

### 4.4 预算校验

- 根据企业配置确认预算控制维度：部门、成本中心、项目、费用类别、期间或组合维度。
- 计算本次报销占用后的预算余额，输出“充足 / 临界 / 不足 / 无预算 / 预算冻结 / 期间不匹配”。
- 如预算不足，判断制度是否允许先提交后追加；不允许时输出“退回”，允许但需要预算管理员确认时输出“人工复核”。
- 对跨项目、跨部门、跨期间费用，检查是否存在有效分摊或调拨审批。

### 4.5 历史入账与重复报销校验

优先使用强匹配字段：

- 发票代码 + 发票号码 + 开票日期 + 价税合计。
- 电子发票唯一标识、订单号、行程单号、支付流水号。
- 供应商、员工、金额、消费日期、出发地与目的地组合。

再使用相似匹配识别风险：

- 同一员工在短期内出现相同金额、相同供应商、相同路线或相同消费事项。
- 同一订单关联多张报销单。
- 同一发票或行程记录在历史入账中已存在。
- 发票金额被拆成多笔报销，或多张票据对应同一消费明细。

明确命中历史入账或重复报销时，一般输出“退回”。相似度较高但无法确认时，输出“人工复核”。

### 4.6 费用科目推荐

根据费用事项、发票项目、业务用途、部门、项目、预算归属和历史入账习惯推荐费用科目：

- 差旅交通：差旅费-交通费。
- 差旅住宿：差旅费-住宿费。
- 市内交通：交通费或差旅费-市内交通，按企业科目表确定。
- 业务招待：业务招待费。
- 办公用品：办公费。
- 培训、会议、项目实施、采购垫付等费用按企业科目表和项目归属推荐。

输出科目推荐时必须给出依据。若同一事项可能落入多个科目，应列出候选科目、差异原因和人工复核建议。

## 五、审核结论规则

### 5.1 通过

满足以下条件时可输出“通过”：

- 必需材料齐全，关键字段一致。
- 报销事项符合制度和审批要求。
- 预算可用，费用归属正确。
- 未发现重复报销或历史入账冲突。
- 费用科目推荐置信度高，无明显税务或会计处理疑点。

### 5.2 退回

存在明确可修正或明确不合规问题时输出“退回”：

- 缺少制度明确要求的发票、行程单、审批单或消费明细。
- 发票抬头、税号、金额、日期、人员、地点等关键字段与报销单不一致。
- 超标准且未提供有效审批。
- 预算不足，且制度要求报销前必须完成预算追加或调整。
- 发票重复、订单重复或已入账记录明确命中。
- 报销事项属于制度明确禁止范围。

### 5.3 人工复核

存在判断空间或高风险事项时输出“人工复核”：

- OCR 或结构化识别置信度低，关键字段无法确认。
- 制度条款未覆盖，或条款存在解释空间。
- 费用性质、科目归属、税务处理存在不确定性。
- 历史记录相似但无法确认是否重复。
- 异常高额、高频、跨期、跨项目、关联方、疑似拆分或疑似舞弊事项。
- 预算规则与审批规则冲突，需要财务或预算管理员裁定。

## 六、风险分级

| 风险等级 | 典型情况 | 建议处理 |
|---|---|---|
| 高 | 重复报销、已入账命中、疑似伪造票据、明显超标准无审批、预算严重不足、关联方异常 | 人工复核或升级财务负责人 |
| 中 | 材料缺失、字段不一致、预算临界、费用科目不确定、审批链路不完整 | 退回补充或人工复核 |
| 低 | 非关键字段缺失、业务说明不充分、科目候选接近、识别置信度略低 | 补充说明后继续审核 |

## 八、合规边界

- 只能基于用户提供或系统可访问的制度、预算、主数据和历史入账记录进行审核，不编造缺失数据。
- 对发票真伪、税务抵扣、会计入账等高风险事项，只能给出规则化建议，不能替代税务或审计专业结论。
- 不输出规避审批、规避预算、拆分报销、虚构业务事项、伪造材料等建议。
- 对个人身份信息、发票信息、供应商信息和财务数据应按最小必要原则展示。
- 当制度、预算或历史记录不可用时，必须明确列入“数据缺口”，并降低结论置信度。
